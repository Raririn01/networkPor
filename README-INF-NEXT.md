# Alien Buu — เจาะลึกหลักสูตรวิทยาการคอมพิวเตอร์ (CS)

เปิดเว็บไซต์: http://ra.local/ (เปิดไซต์ ra ใน Local ก่อน)
หลังบ้าน: http://ra.local/wp-admin/

ปรับเนื้อหาเป็นหลักสูตร CS เพียงสาขาเดียว วันที่ 22 ตุลาคม 2026

## เนื้อหาในเว็บ

1. ภาพรวมและชื่อปริญญา
2. โครงสร้าง 123 หน่วยกิต: ศึกษาทั่วไป 30 วิชาเฉพาะ 81 เลือกเสรี 6 และประสบการณ์ภาคสนาม 6
3. แผน 4 ปี แยกภาคเรียน มีรหัสรายวิชา หน่วยกิต และแท็บเลือกรายปี
4. ผลลัพธ์การเรียนรู้และเกณฑ์สำเร็จการศึกษา
5. ตัวอย่างเส้นทางอาชีพ
6. ข่าวทุนและผลงานรางวัลที่เกี่ยวกับ CS พร้อมภาพจากข่าวคณะ
7. รายชื่ออาจารย์ประจำสาขาและตำแหน่ง พร้อมภาพครบ 7 คน
8. การเตรียมสมัครและประมาณการค่าใช้จ่าย
9. คำถามที่พบบ่อย
10. เอกสารและแหล่งอ้างอิงทางการ

## แก้ไขเนื้อหา

- เมนู **หลักสูตร → วิทยาการคอมพิวเตอร์**: เนื้อหาหน้าแรกและ /program/cs/ ใช้บทความเดียวกัน แยกแต่ละหัวข้อเป็น Classic block สำหรับแก้ข้อความในหน้า Visual
- คลิกข้อความใน Classic block เพื่อแก้ จากนั้นกด **Update** เพื่อบันทึก ไม่ต้องเปิดโหมด HTML หรือเขียนโค้ด
- **รูปแบบเว็บ → ปรับแต่ง → Alien Buu: หน้าแรก**: แก้หัวเรื่องและคำอธิบายส่วนบน
- หลักสูตรเดิมอีก 5 รายการเก็บเป็นฉบับร่าง สามารถกู้กลับได้จากเมนูหลักสูตร
- เมนูมือถือ แท็บปีเรียน และ FAQ ใช้คีย์บอร์ดได้ หากไม่เปิด JavaScript จะแสดงแผนการเรียนทุกปี
