# Alien Buu — เว็บไซต์แนะนำหลักสูตร CS

โปรเจกต์ WordPress ภาษาไทยสำหรับแนะนำหลักสูตรวิทยาการคอมพิวเตอร์ คณะวิทยาการสารสนเทศ มหาวิทยาลัยบูรพา ใช้ธีมที่พัฒนาเองชื่อ `inf-next` (Alien Buu) รองรับมือถือ แผนการเรียนแบบแท็บ และคำถามที่พบบ่อย

## ไฟล์ที่ส่งใน Git

- `app/public/wp-content/themes/inf-next/` — PHP templates, CSS, JavaScript และต้นฉบับเนื้อหาใน `data/`
- `app/public/wp-content/uploads/alien-buu/cs-source-*.png` และภาพอาจารย์ 3 ภาพใน `uploads/2026/10/` — รูปประกอบที่ต้นฉบับเนื้อหาเรียกใช้
- `setup-inf-next.php` และ `setup-alien-cs.php` — สคริปต์ตั้งค่าธีมและสร้างเนื้อหาตัวอย่างผ่าน WP-CLI
- `alien-buu-cs-preview.jpg` — ภาพตัวอย่างเว็บที่บันทึกไว้ อาจต่างจากเว็บไซต์ปัจจุบัน
- `README-INF-NEXT.md` — รายละเอียดเนื้อหาและวิธีแก้ไขผ่าน WordPress

ไม่รวม WordPress core, ธีม/ปลั๊กอินของผู้อื่น, `wp-config.php`, บัญชีผู้ใช้, ฐานข้อมูลจริง, log, ไฟล์สำรอง และค่าลับ โดยกำหนด `.gitignore` ให้รับเฉพาะชุดส่งนี้

## ติดตั้งเพื่อดูผลงาน

ต้องมี WordPress ที่ติดตั้งสำเร็จแล้ว พร้อม PHP และ MySQL/MariaDB ที่รองรับ WordPress รุ่นที่เลือก หากใช้ Local ให้สร้างไซต์ใหม่ก่อน ใช้ WP-CLI สำหรับนำเข้าเนื้อหาตัวอย่าง

1. Clone repository นี้ลงโฟลเดอร์แยกสำหรับทดลอง แล้วติดตั้ง WordPress ใหม่ที่ `app/public/` ภายในโฟลเดอร์นั้น ระวังอย่าเขียนทับธีมและรูปที่มากับ repository
2. ตั้งค่าฐานข้อมูลและบัญชีผู้ดูแลของตนเองผ่านตัวติดตั้ง WordPress ไม่ใช้ฐานข้อมูล production
3. จากโฟลเดอร์รากของ repository เรียกคำสั่งต่อไปนี้ใน shell ที่ใช้ WP-CLI ได้:

   ```sh
   wp eval-file setup-inf-next.php --path=app/public
   wp rewrite flush --path=app/public
   ```

4. เปิด URL ของ WordPress ที่ตั้งไว้ ควรเห็นหน้าแนะนำ CS และหน้า `/program/cs/` หากใช้ Apache ต้องเปิด URL rewriting สำหรับ permalink

หากใช้ Local ที่สร้าง WordPress ไว้แล้ว ให้คัดลอกธีม `inf-next` และรูปที่ระบุข้างต้นลง `wp-content` ของไซต์ใหม่ วางสคริปต์ทั้งสองไว้ที่รากโฟลเดอร์ไซต์ (นอก `app/public`) แล้วเรียกคำสั่งผ่าน Open Site Shell

**คำเตือนการนำเข้า:** สคริปต์เปลี่ยนธีม ชื่อเว็บ และสร้าง/เขียนทับเนื้อหา CS จาก `data/cs-guide.html` รวมทั้งเปลี่ยนหลักสูตรตัวอย่างอื่นเป็นฉบับร่าง จึงให้ใช้กับไซต์ทดลองใหม่ เนื้อหาที่แก้ผ่านหลังบ้านของเว็บจริงอยู่ในฐานข้อมูลและไม่ได้ถูกรวมในชุดส่งนี้โดยอัตโนมัติ

## ตรวจผลงานหลังติดตั้ง

- เปิดหน้าแรกและ `/program/cs/` ตรวจข้อความและรูปประกอบ
- ทดสอบเมนูมือถือ แท็บปีการศึกษา และ FAQ
- เข้าเมนูหลักสูตรในหลังบ้าน แก้ไขข้อความแล้วบันทึก

## แหล่งที่มาและขอบเขต

ข้อมูลและภาพประกอบอ้างอิงคณะวิทยาการสารสนเทศ มหาวิทยาลัยบูรพา ดูลิงก์แหล่งที่มาในหน้าเว็บและ `README-INF-NEXT.md` รูปและข้อมูลจากบุคคลที่สามยังเป็นสิทธิ์ของเจ้าของเดิม การส่งเพื่อการศึกษาไม่ได้โอนสิทธิ์เหล่านั้น

ชุดนี้เป็น source สำหรับส่งงานและสร้างเว็บไซต์ตัวอย่าง ไม่ใช่สำเนา server หรือฐานข้อมูลทั้งหมด ยังไม่ได้ทดสอบติดตั้ง WordPress ใหม่จาก repository นี้ และไม่ได้รวมการตั้งค่า Apache, TLS, Docker หรือมาตรการความปลอดภัยบน production
